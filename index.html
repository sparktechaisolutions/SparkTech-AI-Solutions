Non-Custodial Staking

Consensus rewards & yield mechanics.

Secure the Nexis blockchain by delegating $NEX to verified validator nodes. Earn automated protocol rewards every 12-hour epoch.

1. How Users Earn Rewards

Users participate by delegating any quantity of $NEX to registered validator nodes. Nodes validate transactions and produce blocks, earning protocol block rewards that are distributed proportionally to delegators.

2. Reward Distribution Mechanism

Network rewards are issued algorithmically based on the overall network bonded ratio. If total bonded stake decreases, issuance adjusts upward to incentivize security; if bonded ratio increases, issuance stabilizes.

3. Non-Custodial & Direct Claiming

Tokens remain entirely within your sovereign custody during delegation. Rewards accumulate continuously and can be claimed directly to your connected wallet at any time without locking penalties.

Risk Disclosure: Staking rewards fluctuate based on total network staking participation and consensus parameters. Staking rewards are protocol-driven incentives, not guaranteed financial returns or investments.

Developers & Nodes

EVM-compatible JSON-RPC.

Interact with the Nexis blockchain using your standard Ethereum tooling: ethers.js, viem, web3.py, Hardhat, and Foundry. 

import { createPublicClient, http } from 'viem';
import { nexisMainnet } from 'nexis-viem-chains';

// Connect to high-speed Nexis RPC endpoint
const client = createPublicClient({
  chain: nexisMainnet,
  transport: http('https://rpc.nexis.network/v1')
});

// Fetch current validator block and gas metrics
const blockNumber = await client.getBlockNumber();
const gasPrice = await client.getGasPrice();

console.log(`Nexis Block: ${blockNumber} | Gas: ${gasPrice} wei`);
Knowledge Base

Frequently asked questions.

Essential technical and operational details regarding the Nexis platform and $NEX token.

Nexis is a high-performance Layer-1 blockchain that combines EVM developer compatibility with CometBFT Byzantine Fault Tolerant consensus. It achieves sub-second deterministic block finality, low predictable transaction gas fees, and seamless modular interoperability.
$NEX is the native cryptographic utility token of the platform. Its primary utilities include payment for transaction gas fees, staking collateral for validator node security, on-chain DAO parameter governance voting, and cross-chain bridge settlement liquidity.
Nexis runs an EVM-equivalent state machine on top of a Proof-of-Stake consensus layer powered by CometBFT. This architecture allows developers to deploy standard Solidity smart contracts without rewriting code while maintaining instant finality and zero probabilistic forks.
Token holders delegate their $NEX voting power to verified node operators directly from their private Web3 wallets. Your tokens never leave your custody. Block rewards are minted algorithmically and accrued each 12-hour epoch, with rewards claimable on-demand.
There is no minimum threshold to delegate $NEX to an existing validator node. Anyone holding any amount of $NEX can participate. Running an independent validator node requires meeting hardware specifications and bonding a minimum validator self-stake.
All transactions, block heights, validator signatures, and smart contracts can be audited in real time on our public block explorer, NexisScan, as well as on our verified open-source GitHub repositories.
Official technical support is provided through our developer Discord server, Telegram community channel, and GitHub discussions. The core protocol team and community moderators are available 24/7.
